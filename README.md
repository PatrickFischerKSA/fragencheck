# Debattenwerkstatt · Fragencheck

Eine statische deutschsprachige Webseite zur Vorbereitung von Themenvorschlägen für das Klassenforum. Schüler:innen erfassen den genauen Thementitel und optional einen Beitrag. Sie erhalten Rückmeldung zu allen vier Klassenregeln und kopieren die überarbeitete Fassung ins bestehende Forum.

## Lokal öffnen

[docs/index.html](docs/index.html) im Browser öffnen. Es braucht keinen Build, keinen Server und keinen API-Schlüssel.

## Auf GitHub Pages veröffentlichen

1. Den Inhalt dieses Projektordners in ein GitHub-Repository übertragen. Der Ordner `docs` muss auf der obersten Ebene liegen.
2. Unter **Settings → Pages → Build and deployment** die Quelle **Deploy from a branch** wählen.
3. Den Branch mit den Dateien (zum Beispiel `main`) und den Ordner **/docs** wählen und speichern.
4. Die angezeigte Pages-Adresse mit der Klasse teilen.

## Verhalten

- Vier Prüfpunkte: Entscheidungsfrage, Ja als Änderung, politisches Verfahren, grundrechtskonformer Spielraum für beide Seiten.
- Das Tool markiert erkennbare sprachliche Signale und zeigt pro Kriterium einen nächsten Schritt. Für geeignete Formulierungen bietet es eine direkt übernehmbare Titelvariante.
- Das optionale Prüfraster nimmt die heutige Lage, die Wirkung von Ja/Nein, den politischen Weg und Argumente beider Seiten auf. Es gibt wieder, was die Autorin oder der Autor selbst abgeklärt hat.
- Bei Auslandsthemen erinnert es an den erforderlichen Hinweis im Beitrag zur Aufgabe der Moderation und zum geltenden Rechtsrahmen.
- Der Fragencheck läuft lokal im Browser. Es gibt keine Konten, keinen automatischen Versand und keine dauerhafte Speicherung. Das Klassenforum bleibt der Ort für die Sammlung und Zuteilung der Themen.
- Die Prüfung ermittelt weder die heutige Rechtslage noch die tatsächliche Zuständigkeit und ersetzt keine Prüfung der Argumente. Amtliche Recherchelinks sind auf der Seite hinterlegt.
